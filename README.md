Personal Expense Tracker

A full-stack web application that helps users record, manage,
and analyze their personal expenses.

Problem

People often find it difficult to keep track of their daily
expenses and understand where their money is being spent.

Solution

The Personal Expense Tracker allows users to add, edit,
delete, categorize, and analyze their expenses through
a simple dashboard.

Main Features

- User registration and login
- Add expenses
- Edit expenses
- Delete expenses
- View expenses
- Expense categories
- Monthly spending summary
- Category-wise spending
- Dashboard

Technology Stack

- Frontend: Next.js / React
- Backend: Node.js
- Database: PostgreSQL
- Authentication: Supabase Auth
- Deployment: Vercel / Render
